# Les gabarits des instances

**État au 28/10/2026 [SAVOIR]** — Provenance : gabarits de la mallette (version 0.1). Ce fichier ne contient aucun fait réglementaire. Les mentions imposées par votre règlement intérieur ou votre tutelle passent avant ces gabarits ; la place des rubriques, elle, ne change pas d'un document à l'autre.

Partout : les crochets sont à remplir ; un chiffre sans source reste `[À VÉRIFIER]` ; le bloc « Pour la relecture » se retire avant envoi.

## 1. L'ordre du jour

```
[Instance] du [date], [heure], [lieu ou modalité]
Convoquée par : [qui]          Quorum : [règle — À VÉRIFIER si inconnue]

N°  Point                               Nature         Rapporteur   Pièces jointes            Durée (PENSER)
1   Approbation du procès-verbal du …   Délibération   [rôle]       PV du [date]              5 min
2   [Point qui demande un vote]         Délibération   [rôle]       Note n° 2, projet de délib.
3   [Point d'information]               Information    [rôle]       Note n° 3
4   [Point de débat]                    Débat          [rôle]       Éléments n° 4
5   Questions diverses

Pour la relecture
- Pièces à mettre à disposition avant la séance, et à quelle date : [liste, délai — À VÉRIFIER]
- Points qui relèvent peut-être d'une autre instance : [liste]
```

L'ordre des points : les décisions qui en conditionnent d'autres d'abord (le budget rectificatif avant la convention qu'il finance), l'information ensuite. Un point « Délibération » a toujours une note et un projet de délibération.

## 2. La note aux élus (deux pages au plus)

```
[Instance] du [date] — Point n° [x] — [Délibération | Information | Débat]
Objet : [une ligne]

Décision attendue : [une phrase, avec le verbe : approuver, autoriser, choisir entre…]

1. Le contexte
[Cinq à huit lignes : pourquoi la question se pose maintenant ; ce que l'instance a déjà décidé sur le sujet, avec la date.]

2. Les chiffres
| Ce qu'on mesure | Montant | Source (document, version, date) |
|---|---|---|
| … | … | … |

3. Les options
Option A — [intitulé] : [ce qu'elle implique ; coût ; calendrier ; risque]
Option B — [intitulé] : [même grille]
Ne rien décider ou reporter : [conséquence]
[Seulement si on l'a demandé : « Proposition de [rôle] » — séparée des options.]

4. La décision attendue
[Rappel de la décision ; projet de délibération en annexe.]

Annexes : [liste]

Pour la relecture
- Chiffres à vérifier : [liste, avec la question qui tranche]
- Règles à vérifier (compétence, quorum, majorité) : [liste]
```

Les options sont écrites sur la même grille, pour qu'on les compare ligne à ligne. Une option qui n'est pas réellement ouverte (hors délai, hors compétence) ne figure pas : on dit pourquoi dans le contexte.

## 3. La synthèse d'exécution budgétaire pour le bureau (une page)

```
Exécution budgétaire au [date] — Source : [extraction du logiciel / tableau de suivi], du [date]

En une phrase : [où en est-on, sans adjectif]

| | Crédits ouverts | Réalisé | Taux | Repère : temps écoulé (PENSER) |
|---|---|---|---|---|
| Charges | | | | |
| Produits | | | | |

Les écarts qui comptent (trois au plus, au-dessus du seuil fixé par [qui] : [seuil])
1. [Ligne] : [écart chiffré] — [explication connue, ou À VÉRIFIER]
2. …

Ce que le bureau pourrait avoir à décider : [par exemple, un budget rectificatif — ou « rien à ce stade »]
```

Le seuil de ce qui « compte » est donné par l'utilisateur ; à défaut, tu le demandes au lieu d'en choisir un.

## 4. Les éléments d'orientations budgétaires

```
1. D'où l'on part : exécution de l'exercice précédent et de l'exercice en cours (chiffres sourcés)
2. Ce qui s'impose : ressources connues, engagements pluriannuels, obligations (sourcés)
3. Les hypothèses : [chacune marquée PENSER, avec ce qui la ferait changer]
4. Les priorités : [celles du président et des élus, telles qu'ils les ont formulées — jamais proposées par Claude sans demande]
5. Deux ou trois scénarios chiffrés sur ces hypothèses
6. Les questions pour le débat
```

Les priorités viennent des élus. Si on te demande d'en proposer, elles sont signées du rôle qui les porte et marquées comme propositions.

## 5. La grille de relecture d'un projet de délibération

Tu relèves les incohérences ; tu ne juges pas la légalité.

| Point | La question |
|---|---|
| Instance | Celle qui délibère est-elle compétente, ou a-t-elle reçu délégation (laquelle) ? |
| Visas | Chaque texte visé existe-t-il, dans sa version en vigueur ? [À VÉRIFIER pour chacun] |
| Considérants | Disent-ils pourquoi, et collent-ils au dispositif ? |
| Dispositif | Chaque article dit-il qui fait quoi, pour quel montant, à partir de quand ? |
| Montants | Identiques dans la note, la délibération et les annexes ? Les totaux, refaits en code, tombent-ils juste ? |
| Dates et durées | Cohérentes entre elles et avec le calendrier de l'instance ? |
| Imputation | Le compte ou la ligne budgétaire est-il cité, et existe-t-il des crédits ? |
| Annexes | Chaque annexe citée existe-t-elle, dans la bonne version ? |
| Vote | Les modalités de vote et le quorum ont-ils leur place, comme le demande votre cadre ? [À VÉRIFIER] |

Rendu : un tableau « endroit / ce qui est écrit / ce qui ne colle pas / question à poser », puis la liste de ce qui doit être soumis au service juridique ou à la tutelle. Rien n'est corrigé en silence dans le texte.
